# 進度報告

給指導教授的書面報告。數據取自 `output/tables/`，圖取自 `output/figures/`，
書目為 `references.bib`（108 筆，1012 V1 全數引用）。

## 維護中的三份

| 檔案 | 頁數 | 定位 |
|---|---|---|
| `進度報告_1012_V1.tex` | 78 | **現行的完整版。** 由 `tools/make_1012_v1.py` 自 1005 V2 產生 |
| `進度報告_1012_摘要版.tex` | 13 | 問題、解決方案、策略三節；非節錄而是重寫 |
| `進度報告_1005_V2.tex` | 69 | **1012 V1 的母本，只編輯這一份** |

`1012_V1` 不直接編輯。其與母本的差異全部寫在 `tools/make_1012_v1.py`，
以 `sub()` 加 `assert` 施作，故 V2 改動而錨點失配時重產會**立刻失敗**
而非默默漏掉。改完 V2 之後先跑 `make gen`。

## 編譯

需要 XeLaTeX（中文用 `ctex` 加 `fontset=macnew`）。TinyTeX 裝在
`~/Library/TinyTeX` 而未加入 PATH，Makefile 已代為處理。

```sh
make            # 三份都編
make v1012      # 完整版
make brief      # 摘要版
make v2         # 母本
make gen        # 由 V2 重新產生 1012 V1 的 .tex
make clean      # 清中間檔
```
