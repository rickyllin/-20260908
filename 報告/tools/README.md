# 報告的產生流程

```
進度報告_1005_V2.tex          母本。只編輯這一份。
        │
        ├── make_v3.py ───────► 進度報告_1005_V3.tex            精簡版（主文 40 頁以內）
        └── make_statistics_version.py ──► 進度報告_1005_V2_無精算概念.tex
```

改完母本之後：

```bash
make -C 報告 gen     # 重新產生兩個衍生版的 .tex
make -C 報告 all     # 三份一起編譯
```

兩個產生器都以 `sub()` 搭配 assert 施作，**若母本中被改到的段落正好是產生器
要刪要改的對象，程式會中止並指出是哪一段**，不會默默產生錯誤的版本。
遇到這種情形，把該處的錨點更新為母本的新文字即可。
