## V3 相對於 V2 所做的四件事

所刪者皆為「數值核對」或與既有表格重複的圖，其結論一律改以一句敘述保留，
**數字一個不少**。

| 表 四個二階解析量的數值核對 | 15 個 $\mu$ 的核對 | 四格圖＋本文的比值敘述 |
| 表 逐年齡對照（選列） | 兩個門檻的逐年齡驗證 | 本文已逐組列出數字 |
| 表 校正代價的有效範圍 | 分段比值 | 本文已列 $0.85$--$1.09$ 與 $523.6$ 對 $85.0$ |
| 表 人口年齡結構的影響 | 三種結構對照 | 本文已列三組 $e_0$ 偏誤 |
| 表 兩個門檻的比較 | 概念對照 | 改寫為一句敘述 |
| 表 逐年齡段的均方根誤差 | 五個年齡段 | 本文已列五段數字 |
| 表 平均餘命序列的震盪幅度 | 粗糙度與全距 | 本文已列三個規模的數字 |
| 表 逐格校正與僅校正 $\alpha$ | 疊加設計的檢驗 | 本文已列全部七個數字 |
| 表 偏誤方向對各業務線 | 三條業務線 | 本文已逐線敘述 |
| 圖 三項指標隨規模變化 | 與表重複 | 表 估計量比較 |
| 圖 逐年齡均方根誤差 | 與表重複 | 本文敘述 |
| 圖 平均餘命逐年序列 | 與表重複 | 本文敘述 |

V3 留下的十二表六圖為：偏誤的 $c_0$ 依賴、三種分布的兩分支對照、
閉式與實測的對照、逐年齡的二階量、可行性分級、成分分解、三種損失的最適權重、
估計量比較、平均餘命的偏誤與離散、參考母體修勻的七情境、真實資料抽薄、
平均餘命的分工；以及震盪與偏誤、四個二階量、$\alpha$ 帶、$\beta$ 帶、
可行性檢定的輸出、取捨圖。

### 二、去重

- 刪去結論中與玖之一重複的限制逐項回顧。
- 刪去肆節與參節重複的兩段：雙射與訊息不損失的論證、
  Corollary 1 為恆等式的說明，兩者在參之二已各寫過一次。
- 刪去伍之四開頭與段中重複的一句。

### 三、把五處回扣段壓成一句

依 1004 建議新增的五處文獻回扣（Hunt and Blake 的不變變換、
Chen and Roth 的 Proposition 1、Kosmidis and Firth 的輸入條件、
Breslow and Lin 的同型性、崩潰點所涵蓋的估計量類別），
V2 寫完整的推導對應，V3 只留結論一句。

### 四、精簡輔助說明句

捌、陸、柒、肆四節的「此處須明白寫出」、「值得特別指出」、
「本文原先的解釋是……」一類的鋪陳語一併精簡，約三十處。

### 五、版面

行距改為單行、表身字級降一級、圖寬由 `\textwidth` 改為 `0.86\textwidth`、
頁邊界 2.5 cm 改為 2.2 cm，為投稿稿的慣例。
