# 三種估計方法的評估：MTL、LTS、REML

針對「最大截尾概似（MTL）、最小截尾平方（LTS）、殘差最大概似（REML）是否能改善小人口 LC 估計」的研究與實測。

資料：女性 2001–2024，22 齡組 × 24 年；真值取自 LC 配適（漂移 $-0.3678$、$\sigma=0.7496$），與 0929 報告一致。

---

## 零、結論先講

| 方法 | 裁決 | 理由 |
|---|---|---|
| **LTS**（最小截尾平方） | **不建議** | 與你的失效機制正交；大樣本下災難性失效（SSE 為卜瓦松的 43 倍） |
| **MTL**（最大截尾概似） | **不建議** | 任何截尾比例都輸給未截尾的卜瓦松 MLE；截尾越多越差 |
| **REML**（殘差最大概似） | **建議採用，但它不是穩健方法** | 它是變異成分的偏誤校正，恰好解決你 §六、八 步驟二 失效的那個問題 |

三者之中只有 REML 值得投入，而且理由與你原本的預期不同——**它與「穩健統計」無關**。下面分別說明。

---

## 一、為什麼截尾類方法在這個問題上行不通

### 1.1 你自己已經證明了問題不是污染

截尾方法（LTS、MTL、LMS）全部建立在同一個假設上：**絕大多數觀測來自模型，少數來自別處**。它們的設計目標是高崩潰點——讓少數離群值無法主導估計。

但你的 0929 報告表 15 的變體 E 已經排除了這個情境。該變體對真值 $\log m$ 加均值為零、變異數與卜瓦松相當的噪音後做 SVD：不涉及對數轉換、不存在零格、無加權失衡、噪音對稱且期望為零、**沒有任何離群值**。結果 $N=5\times10^4$ 時漂移項偏誤仍達 0.347，甚至略大於標準 LC 的 0.305。

**純粹對稱的異質變異噪音，在等權重秩一分解下就足以產生系統性偏誤。** 既然沒有東西可以截，截尾自然無從發揮。

### 1.2 效率代價極高

古典結果：LTS 在常態下相對於 OLS 的漸近效率僅約 **8%**，LMS 的相對效率隨 $n$ 增大趨近於零；相對地 Huber（$t=1.345\sigma$）與 Tukey bisquare 皆可達約 95%，中位數 63.7%。

在污染確實存在的問題上，付出這個效率代價換取崩潰點是划算的。但你的問題是**資訊不足**——每格死亡數的中位數只有 1,201、最少 37，鄉鎮市區層級更有三成格子為零。在資訊本就稀薄的情境下丟掉 10% 的觀測，方向完全相反。

### 1.3 卜瓦松的截尾概似理論需要正的計數

Müller 與 Neykov（2003, *JSPI*）建立了 GLM 中截尾概似估計量的崩潰點理論。對數線性（卜瓦松）模型的結果建立在一個條件上：

> 函數 $\gamma_z(\theta)=-z\theta+\exp(\theta)+\log(z!)$ 在 $z>0$ 時為次緊緻（sub-compact）。

$z=0$ 時 $\gamma_0(\theta)=\exp(\theta)$，當 $\theta\to-\infty$ 時趨近於零，不具次緊緻性。換言之，**零計數格可被 $\theta\to-\infty$ 完美配適，崩潰點理論在此失效**。而零格正是小人口情境的核心特徵（$N=10^4$ 時佔四成）。這不是實作困難，是理論前提不成立。

**其四，LTS 在大樣本下災難性失效。** $N=5\times10^6$ 時 SSE($\beta$) 為卜瓦松的 43 倍、相關係數由 0.981 崩至 0.258。這遠超過 8% 效率所能解釋的程度，下一節說明原因。

## 三、截尾掉的是哪些格——機制證據

這是全部實測中最值得寫進論文的一項。逐年齡統計保留比例（$N=5\times10^6$，模型正確、無零格、無離群值）：

| 年齡組 | MTL 保留率 | LTS 保留率 | $\beta_x^{\text{true}}$ |
|---|---|---|---|
| 0 | 0.98 | 0.94 | 0.0469 |
| **1–4** | 0.99 | **0.37** | **0.1107**（最大） |
| **5–9** | 0.98 | **0.42** | **0.0785**（次大） |
| 10–14 | 0.97 | 0.61 | 0.0423 |
| 15–19 | 0.95 | 0.79 | 0.0520 |
| 40–44 | 0.96 | 1.00 | 0.0330 |
| **70–74** | **0.87** | 1.00 | 0.0650 |
| **80–84** | **0.76** | 1.00 | 0.0429 |
| **85–89** | **0.74** | 1.00 | 0.0324 |
| 100+ | 0.94 | 0.91 | 0.0058 |

**LTS 丟掉了 63% 的 1–4 歲組與 58% 的 5–9 歲組——正是 $\beta_x$ 最大的兩個年齡。** 機制很直接：在 $\log$ 尺度上，$|\beta_x\kappa_t|$ 最大的年齡也是偏離秩一結構時殘差最大的年齡，因此「最不合模型」的格恰好是「攜帶最多趨勢訊號」的格。截掉它們之後剩餘的格更貼合秩一結構，但 $\beta$ 的形狀資訊已被丟棄——這就是相關係數 0.258 的來源。

**MTL 則偏好丟掉 70–94 歲（保留率 0.74–0.87）——死亡數最多的年齡。** 因為卜瓦松逐格對數概似的絕對值隨計數量級成長，高計數格的概似貢獻本就較低，截尾規則因而系統性地移除資訊量最大的格。

**兩種截尾規則丟掉的是不同的格，但都是錯的格，而且原因結構性不同。** 在一般迴歸中離群值是隨機散布的；在具結構性異質變異的雙線性模型中，「最差配適」與「最具資訊」高度重疊。

這一段可以獨立成為論文的一小節，標題大致是「截尾規則在雙線性模型中的選擇偏誤」，而且它是你的資料獨有的證據，不是引用來的。

## 四、REML 為什麼不同

### 4.1 先修正一個分類

REML 被你歸在穩健統計概念裡，但**它不是穩健方法**。它與影響函數、崩潰點、污染鄰域毫無關係，崩潰點與 ML 相同（皆為零）。

REML 處理的是另一件事：**最大概似對變異成分的向下偏誤**。ML 在估計變異成分時未扣除估計固定效果所消耗的自由度，因而系統性低估；REML 將概似對固定效果積分後再最大化，得到不偏（或偏誤大幅降低）的變異成分估計，且**保證非負**。

### 4.2 它恰好接到你的哪一個問題

你 0929 報告 §六、八 步驟二 的問題是：

> 由 $\hat\kappa_t=\kappa_t+u_t$ 可得 $\widehat{\mathrm{Var}}(\Delta\hat\kappa)\approx\sigma^2+\mathrm{Var}(\Delta u)$，以參數式拔靴估計 $\mathrm{Var}(\Delta u^*)$ 後扣除即可。惟 $N=5$ 萬時 $\sqrt{\hat V_u}=7.36$ 大於未校正的 $\hat\sigma=2.30$，兩個大噪音量相減並不穩定，是動差法去偏的典型病症，因此去偏約需 $N\ge20$ 萬方為可行。

**這是一個變異成分分離問題，不是穩健問題。** 而變異成分分離正是 REML 的本職。把你的設定寫成狀態空間模型：

$$\text{觀測：}\ \hat\kappa_t=\kappa_t+u_t,\qquad u_t\sim N(0,\tau_t^2)$$
$$\text{狀態：}\ \kappa_t=\kappa_{t-1}+\delta+\varepsilon_t,\qquad \varepsilon_t\sim N(0,\sigma^2)$$

這就是「隨機漫步加噪音」模型。狀態空間模型與線性混合模型互為表述（Statistica Sinica 1997 的 mixed model representation），其中狀態擾動扮演隨機效果、漂移 $\delta$ 為固定效果，因此 REML 直接適用。

兩個關鍵優勢：

**其一，$\tau_t^2$ 不必估計，可由卜瓦松資訊矩陣直接代入。** 給定 $\alpha,\beta$，$\kappa_t$ 的 Fisher 資訊為 $\sum_x\hat\mu_{x,t}\hat\beta_x^2$，故

$$\hat\tau_t^2=\Big(\textstyle\sum_x\hat\mu_{x,t}\hat\beta_x^2\Big)^{-1}$$

這是免費的——你的卜瓦松 LC 迭代中已經算過這一項（它就是 $\kappa$ 更新式的分母）。

**其二，不需要相減。** 差分後 $d_t=\Delta\hat\kappa_t=\delta+\varepsilon_t+u_t-u_{t-1}$，其共變異結構為

$$\mathrm{Var}(d_t)=\sigma^2+\tau_t^2+\tau_{t-1}^2,\qquad \mathrm{Cov}(d_t,d_{t+1})=-\tau_t^2$$

$\sigma^2$ 是在概似中被估計出來的，而非兩個估計量相減的餘數，因此**結構上不可能為負**，動差法的病症自動消失。

## 五、REML 的實測結果

### 5.1 $\sigma$ 的估計（真值 0.7496，各 20 次重複）

| $N$ | 方法 | 中位數 | 偏誤 | IQR | 可行率 |
|---|---|---|---|---|---|
| **$5\times10^4$** | naive $\mathrm{sd}(\Delta\hat\kappa)$ | 2.5450 | $+1.7954$ | 1.08 | — |
| | 動差法去偏（報告） | 2.4360 | $+1.6865$ | 1.22 | **10%** |
| | 狀態空間 ML | 0.6899 | $-0.0596$ | 0.76 | 100% |
| | **狀態空間 REML** | **0.8974** | $+0.1479$ | 0.73 | **100%** |
| **$2\times10^5$** | naive | 1.0701 | $+0.3205$ | 0.26 | — |
| | 動差法去偏 | **0.6705** | $-0.0790$ | 0.47 | 85% |
| | 狀態空間 ML | 0.5430 | $-0.2066$ | 0.15 | 100% |
| | 狀態空間 REML | 0.6058 | $-0.1438$ | **0.16** | 100% |
| **$10^6$** | naive | 0.8267 | $+0.0772$ | 0.16 | — |
| | 動差法去偏 | **0.7081** | $-0.0415$ | 0.16 | 100% |
| | 狀態空間 REML | 0.6623 | $-0.0872$ | **0.12** | 100% |

**$N=5$ 萬是關鍵那一格。** 動差法在該規模僅 10% 可行，退回未校正值後偏誤高達 $+1.69$；狀態空間法偏誤在 $-0.06$ 至 $+0.15$ 之間，且 100% 可行。**這把去偏的操作下限由 $N\ge20$ 萬推進到至少 $N=5$ 萬**，正是你報告中標記為未解決的區間。

$N\ge20$ 萬時兩者互有勝負：動差法的中位數偏誤較小，狀態空間法的 IQR 較小（$N=10^6$ 時 0.12 對 0.16）。**兩法互補而非取代**，實務建議應為：$N<20$ 萬用狀態空間，$N\ge20$ 萬兩者皆可、或取兩者的平均。

另注意 REML 與 ML 的比較並非一面倒：$N=5$ 萬時 ML 反而較接近真值（$-0.060$ 對 $+0.148$），$N\ge20$ 萬時 REML 較佳（修正了 ML 的向下偏誤）。**不宜只報 REML 而略過 ML**，兩者一起報才誠實。

| $N$ | 方法 | 區間寬度 | 涵蓋率 |
|---|---|---|---|
| $5\times10^4$ | O 不可約下限 | 1.717 | 0.79 |
| | P 現行作法（SVD） | 7.126 | 0.40 |
| | C 卜瓦松 + 動差去偏 | 4.081 | 0.99 |

| | R 卜瓦松 + 狀態空間 REML | 1.602 | 0.70 |

$N=5$ 萬時，狀態空間版的寬度 1.640 幾乎完全貼合不可約下限 1.717（動差法版為 4.081，2.4 倍）。動差法在該規模的 0.99 涵蓋率是靠 2.4 倍寬度換來的，**與你在報告中批評現行作法「涵蓋 0.95 是靠 2.7 倍寬度換來」是同一種假象**，不應解讀為優勢。

$N=2\times10^5$ 時兩者基本打平。

### 5.3 尚未解決的部分

$N=5$ 萬時寬度已對（1.640 對下限 1.717）但涵蓋仍只有 0.67。**殘餘缺口不在寬度而在位置**——即 $\hat\kappa_T$ 這個預測初始值本身的誤差，它是單一年份的估計值，誤差不隨配適期長度 $T$ 縮小。

這與你報告 §六、八之（三）的診斷完全一致，也再次指向 Stoeldraijer et al.（2018）所述的初始值取捨。**狀態空間方法在這裡還有一個未用上的優勢**：Kalman 平滑子給出的 $\kappa_{T|T}$ 是把整條序列的資訊納入後的後驗估計，理論上優於單點的 $\hat\kappa_T$。這是下一步可做、且與本節架構完全相容的延伸。

## 六、實作路徑

附檔 `reml_kappa.R` 提供三個函式：

- `tau2_from_info()`：由卜瓦松配適取出 $\hat\tau_t^2$（一行，重用既有的 $\kappa$ 更新分母）
- `sigma_state_space()`：狀態空間 ML／REML 估計 $\sigma$，含 `restricted` 開關
- `trimmed_lc()` 與 `lts_lc()`：截尾變體，供你重現上述負面結果

計算成本可忽略：$\sigma$ 的估計是 23 維三對角矩陣上的一維最佳化，每次不到 0.01 秒；相較之下動差法每次需要 $B$ 次完整的卜瓦松 LC 配適。**狀態空間版比動差法快兩到三個數量級**，這一點在你要跑大規模模擬時很實際。

## 七、對論文架構的建議

這批結果可以放在兩個位置：

**負面結果（截尾類）放在穩健估計章的開頭，作為「為什麼不走這條路」的論證。** 它有三層證據，強度遞增：理論（崩潰點需 $z>0$、效率 8%）、實測（沒有一個變體勝過卜瓦松 MLE）、機制（LTS 丟掉 $\beta$ 最大的年齡、MTL 丟掉計數最多的年齡）。第三層是你獨有的，應該是這一節的重點。

這一節同時也補強了你先前那個論證——**你的問題不是污染**——並把它從「變體 E 的間接證據」升級為「直接檢驗了污染設計的方法並證明其失效」。

**正面結果（REML）併入 §六、八 步驟二，作為動差法的替代與延伸。** 建議的寫法是把現有的動差法保留為對照，兩法並列，並明確指出各自的適用範圍。這比替換掉原方法更誠實，也更完整。

## 八、限制與待查

1. **重複次數偏低**（截尾實驗 25 次、REML 20 次、涵蓋 15 次），是為了快速給出方向。論文數字建議提高到 100 次以上，特別是涵蓋率那組——15 次重複 × 10 個預測期的涵蓋率標準誤仍大。

2. **$\hat\tau_t^2$ 是插入式的**，僅取 $\kappa_t$ 的 Fisher 資訊，未納入 $\hat\alpha,\hat\beta$ 的不確定性透過模型傳導的部分，因而低估。這可能是 $N\ge2\times10^5$ 時狀態空間法略偏低的原因之一，值得以拔靴法檢驗。

3. **MTL 的實作採 FAST-TLE 式的迭代重加權**（配適 → 依逐格概似保留前 $h$ 格 → 重配適），非全域最佳解。全域搜尋在 528 格上不可行，但迭代版可能落在局部解。若要寫進論文，宜註明此點，或以多重起始值檢驗。

4. **書目核對**：LTS 的 8% 效率與 LMS 效率趨近零為教科書標準結果，但我引用的是課程講義而非原始文獻（Rousseeuw 1984；Hössjer 1994），引用前請回查原文。Müller 與 Neykov（2003）的次緊緻性條件我讀的是摘要層級的描述，正式引用前請取得全文確認 $z>0$ 條件的確切陳述與適用範圍。
