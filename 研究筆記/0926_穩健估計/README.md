# 0926 研究筆記：穩健估計、異質變異與 EDA 診斷

承 0922 會議指導（先由資料分布與偏誤特性論證方法的必要性）與 0929 進度報告
第肆節之三（T-ratio 診斷）、第陸節之七（偏誤來源階梯分解）的結果，
本批筆記探索「換損失函數／換分配假設／換權重」三條路線。

六份筆記依產生順序排列，前後有承接關係。

| 檔案 | 主題 | 最重要的一項結論 |
|---|---|---|
| `MTL_LTS_REML_評估.md` | 截尾類（MTL／LTS）與狀態空間 REML | 截尾類全面失效，且機制可指名：LTS 丟掉 β 最大的年齡、MTL 丟掉死亡數最多的年齡。REML 則把 σ 去偏的下限由 N≥20 萬推進到 N=5 萬 |
| `小樣本穩健方法_候選清單與實測.md` | 候選方法四級分類 | 加權 SVD 的權重改用 μ̂ 而非觀測 D，β 相關由 0.242 躍升至 0.634（修正 0929 報告變體 C 的評價）；BBP 相變門檻預測了報告表 12 的每一格 |
| `優先順序4到7_實測結果.md` | Kalman／Firth／奇異值收縮／Fay–Herriot | Firth 把卜瓦松 MLE 的發散率由 35% 降為 0；Fay–Herriot 經驗貝氏免調參即追平 oracle LASSO，使第柒節的 λ 選擇問題消失 |
| `條件與方法_適用性評估.md` | 方法 × 條件的系統評估 | 條件可壓縮為單一維度 ρ=θ/c^(1/4)；α 的偏誤在 N=10⁴ 的 5–9 歲組由 SVD 的 +2.15、卜瓦松的 −19.29 降為 Firth 的 +0.070 |
| `EDA判讀_從資料分布決定方法.md` | 把模擬結論翻譯成事前看圖可判斷的量 | 四個診斷（死亡數量級／零格位置／噪音變異跨度／s₁ 對噪音上緣），前三者拿到資料即可算，第四者只需一次便宜的預備配適 |
| `轉向穩健估計_素材增減與緒論鋪陳.md` | 論文架構建議 | 本研究的失效模式是「資訊不足加異質變異」而非古典的「污染」（變體 E 已證明無離群值亦有偏誤），故不可照搬崩潰點／影響函數的語彙 |

## 對應的程式

四份工具箱已歸入 `R/core/`，皆為純函式定義、無副作用、不讀取資料：

| 檔案 | 主要函式 |
|---|---|
| `R/core/eda_diagnostics.R` | `lc_eda()`、`plot_lc_eda()` — 四張 EDA 診斷圖與數值摘要 |
| `R/core/heteropca_lc.R` | `lc_wsvd()`（w=μ̂ 的加權 SVD）、`lc_heteropca()`、`bbp_threshold()` |
| `R/core/fh_firth_kalman.R` | `fh_shrink()`、`lc_poisson_firth()`、`kalman_jumpoff()`、`bbp_alignment()`、`bbp_min_population()` |
| `R/core/reml_kappa.R` | `tau2_from_info()`、`sigma_state_space()`、`lc_sigma()`、`trimmed_lc()`、`lts_lc()` |

## 使用這批結果時的注意事項

1. **重複次數偏低。** 各表為 15–40 次重複，僅供定向；正式寫入論文的數字需
   提高到 100 次以上，涵蓋率那組尤然（15–18 次重複的涵蓋率標準誤約 0.03–0.04）。
2. **卷期未逐項查證。** 各筆記第七節（或末節）列出待查書目，引用前需回查原文。
3. **BBP 門檻為白噪音近似。** 以 σ_eff=√(mean(1/μ̂)) 作等效 σ，門檻落點與
   超臨界區的還原程度均與實測吻合，但嚴格而言需補白化後的對照。
4. **Firth 比較存在倖存者偏誤。** 卜瓦松的統計量僅計收斂的重複，Firth 為全部，
   故該比較對卜瓦松有利，實際差距大於表上所示。
