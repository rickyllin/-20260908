## 使用這批結果時的注意事項

1. **重複次數偏低。** 各表為 15–40 次重複，僅供定向；正式寫入論文的數字需
   提高到 100 次以上，涵蓋率那組尤然（15–18 次重複的涵蓋率標準誤約 0.03–0.04）。
2. **卷期未逐項查證。** 各筆記第七節（或末節）列出待查書目，引用前需回查原文。
3. **BBP 門檻為白噪音近似。** 以 σ_eff=√(mean(1/μ̂)) 作等效 σ，門檻落點與
   超臨界區的還原程度均與實測吻合，但嚴格而言需補白化後的對照。
4. **Firth 比較存在倖存者偏誤。** 卜瓦松的統計量僅計收斂的重複，Firth 為全部，
   故該比較對卜瓦松有利，實際差距大於表上所示。

### 與 EDA 診斷② 的連結

零格比例與 |α 偏誤| 的 Spearman 相關（逐年齡，22 組）：

| N | 標準 LC | Firth |
|---|---|---|
| 10⁴ | 0.863 | 0.915 |
| 5×10⁴ | 0.881 | 0.789 |
| 2×10⁵ | 0.740 | 0.484 |

**判讀要小心：Spearman 對尺度不變，故不可用它顯示 Firth 的改善。**
它要說的是另一件事——**零格比例可以事前指出 α 偏誤會落在哪些年齡**
（ρ=0.74–0.88），而 Firth 改善的是同一批年齡上的**量級**（N=5×10⁴ 時
最大偏誤 0.866 → 0.068，12.7 倍）。Firth 的 ρ 隨 N 增大而下降
（0.915 → 0.789 → 0.484），表示其殘餘偏誤在大 N 時已不再由零格驅動。

### 一項對本批筆記的修正

`小樣本穩健方法_候選清單與實測.md` §2.4 有一句「T=24 年、N≤5 萬時，
β̂ 在統計上與一個隨機方向無法區分」，並建議原封不動寫進論文。
**這句話須限定於未收縮的 SVD。** 本次實測在 N=5×10⁴：
標準 LC 的 cor(β)=0.037（確實與隨機方向無異），但 Firth+FH 達 0.542。

BBP 門檻界定的是**未正則化的秩一分解**能還原多少，不是所有估計量的上界；
收縮估計量可以跨過它。`R/core/eda_diagnostics.R` 的診斷④ 在 N=5×10⁴ 判為
「不可還原」，就估計量選擇而言是**偏保守**的——正確的寫法是
「不可還原 → 不要用 SVD 估 β；改用卜瓦松/Firth + FH 收縮」。
