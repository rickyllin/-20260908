## 第一份：修勻、加權與中心化的代數關係

起點是把三個工具寫進同一組正規方程式
$\hat r=(W+h\Delta^{\top}\Delta)^{-1}W(y-b)$——資訊加權供 $W$、
修勻供 $h\Delta^{\top}\Delta$、中心化供位移項 $b$。五項結果：

1. **沿年齡修勻後校正量須輸送過修勻算子**（扣 $Sb(\hat\mu)$ 而非 $b(\hat\mu)$）。
   原樣扣除時 $\alpha$ 最大偏誤隨平滑量單調爆開（$0.672\to11.072$），
   輸送後在三十三倍的 $\lambda$ 全距內只落在 $0.213$ 至 $0.303$。
2. **沿時間修勻則不需輸送**：對任一凸的 $J(\Delta^z r)$，$W$ 加權平均恆不變，
   $z\ge2$ 時加權最小平方斜率亦恆不變，故 $\hat\alpha$ 與漂移精確不動。
3. **該不變性來自差分算子的零空間而非二次範數**，故改用 $L_1$
   （trend filtering）兩項保證原封不動；推廣至任何只透過 $\Delta^z r$
   依賴 $r$ 的先驗（含 horseshoe，以 Gibbs 抽樣核對）。
4. **高階修正有三種對象**，其中插入式誤差的兩項展開在幼年組幾乎互相抵銷，
   故直接的二階校正在數值上不穩定。
5. **修勻的先決條件是「懲罰的零空間須包含所相信的模型」**——
   $z=2$ 的零空間即對數死亡率在格子上成一次式，
   沿年齡是 Gompertz 法則、沿時間是固定漂移，兩者皆為本研究已有的假設。
   並給出可在配適前計算的逐年齡診斷，以及零格的三級分類。

**已摘入主報告者**：無。第 2、5 項的零空間條件於跨國評估中被引為
秩一與固定漂移兩個假設的來源（見 `../跨國適用性評估.md`）。

## 第二份：不取對數的小人口估計

回應「若不經過對數轉換，其他方法在小樣本下是否仍穩健」。
把各法寫成同一族估計方程
$\sum w\,\psi(h(D)-h(\mu))\,\partial h(\mu)/\partial\theta=0$，
問題即化為轉換 $h$、權重 $w$、損失 $\psi$ 三個選擇。四項結果：

1. **$h$ 取恆等時估計方程恆為無偏**（$E[D-\mu]=0$），
   故本研究所處理的偏誤完全是轉換造成的；但代價是解的存在性。
2. **對數尺度加權最小平方所對應的變異函數為 $\mu^2/w$**，
   故 $w=\mu$ 給 Poisson 擬分數、$w=1$ 給固定變異係數。
   \textbf{亦即標準 Lee-Carter 隱含假設固定變異係數而非 Poisson，
   而資訊加權正是這一處的修正}（分數向量的相關由 $0.588$ 升至 $0.99998$）。
3. **權重與中心化的作用域精確分離**（$2\times2$ 的設計），
   據此得出分離式設計：$\alpha$ 維持等權列平均、加權只用於秩一結構。
4. **Anscombe 尺度可用而不宜為主**；有界影響的截斷買不到東西，
   蓋因病灶是整列沒有資訊而非少數離群值。

**已摘入主報告者**：第 3 項的分離式設計（V1 第柒節之三與摘要版的流程方塊）。
第 2 項的命題尚未摘入，而它使資訊加權由權宜裝置變成變異函數的修正，
值得納入——列為後續。
